# 分阶段交付路线

每个阶段都必须形成可独立运行、可验收的版本。上一阶段通过后再扩大范围。

## 阶段一：单用户核心服务（已完成）

目标：建立可信的数据与身份基础，并跑通手动保存和找回。

- [x] Go 单进程应用与内嵌 Web UI
- [x] SQLite 单文件存储与自动建表
- [x] Passkey-only 初始化和登录
- [x] 一次性初始化链接与 CLI 恢复链接
- [x] 服务端 WebAuthn ceremony 和应用会话
- [x] 手动新增、URL 规范化、去重
- [x] 标题、网址、备注基础检索
- [x] 稍后阅读、收藏、编辑和删除
- [x] 安全响应头、Origin 检查和最小化 Cookie 权限
- [x] Dockerfile 与 Compose 基础

验收：测试、静态检查和二进制构建通过；本地服务健康检查、初始化状态、WebAuthn 注册起始、书签新增、去重和中文基础查询通过。

## 阶段二：Chromium 收集与轻量归档（已完成）

目标：把“手动粘贴链接”升级为“一键保存”，并在低配 VPS 上可靠保存正文。

- [x] Manifest V3 Chromium 扩展
- [x] `activeTab` 临时页面权限
- [x] 工具栏、快捷键和右键菜单保存
- [x] 扩展设备配对与 capture-only Token
- [x] 幂等 Capture API
- [x] SQLite 持久化后台任务队列
- [x] 限并发、限时、限大小的 HTTP 抓取
- [x] 正文提取、清理和压缩 Blob 存储
- [x] 登录页/SPA 的显式浏览器端正文提交
- [x] 归档失败可见、可重试且不影响 URL 保存

验收：在 Chrome 中一键保存公开网页，接口立即响应，后台归档完成；抓取失败仍保留书签；扩展无持续全站访问权限。

## 阶段三：中文找回与数据可靠性（已完成）

目标：让数万条中文书签仍然容易找回，并保证可以离开或恢复系统。

- [x] SQLite FTS5 索引
- [x] 中文二元词与中英文混合查询
- [x] 标题、标签、备注和正文分字段加权
- [x] 命中片段与无结果反馈
- [x] 标签编辑
- [x] HTML、JSON、CSV 导出
- [x] 数据目录备份与恢复校验
- [x] 存储用量与归档状态面板
- [x] Docker 部署、升级和迁移文档

验收：真实中文查询集通过；JSON、CSV 和 HTML 导出内容完整；备份包含数据库与归档 Blob，解包恢复后书签数量、内容哈希和 Blob 内容一致。
